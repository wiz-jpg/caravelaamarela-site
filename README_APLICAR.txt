PATCH CARAVELA AMARELA

Este pacote NÃO inclui a pasta assets.
Objetivo: atualizar a estrutura, a página For Artists e a navbar sem substituir imagens/logos que já estavam corretos.

Como aplicar:
1. Abre a tua pasta atual do site.
2. Copia estes ficheiros para lá, substituindo os ficheiros com o mesmo nome:
   - index.html
   - wildchains.html
   - devil-of-a-woman.html
   - for-artists.html
   - styles.css
   - script.js
   - package.json
   - vite.config.js
3. NÃO apagues nem substituas a pasta assets.
4. Corre:
   npm install
   npm run dev

Navbar:
- Roster
- Palcos / Stages
- Para Artistas / For Artists em destaque outline
- Contactos / Contact em destaque CTA
